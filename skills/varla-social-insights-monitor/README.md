# Varla 社媒洞察核对 / Varla Social Insights Review

**简体中文** | [English](README.en.md)

从授权的 Meta 页面读取表现，标记采集日期与缺失项，再按准确链接准备飞书更新。

## 功能特性

- 后台可见指标复核
- 准确帖子链接匹配
- 范围受控的飞书更新检查

## 这个包里有什么

| 内容 | 位置 |
| --- | --- |
| Skill 指令 | [SKILL.md](./SKILL.md) |

本项目是 Codex 工作流/脚本 Skill，没有另外一套需要启动的网页后台。

## 1. 先准备程序

无需另装程序。准备已登录的 Codex 和下方输入资料即可；带 Python 脚本的项目再按本页脚本说明安装依赖。

## 3. 第一次怎么用

| 准备项 | 内容 |
| --- | --- |
| 输入 | 有权限访问的 Meta 数据、帖子链接和指定表格。 |
| 输出 | 来源与日期齐全的指标核对表。 |

```text
使用 varla-social-insights-monitor，先核对我提供的 Meta 截图与帖子链接，只生成对照表，缺失指标写 unavailable。
```


## 当前限制与常见问题

这是工作流 Skill；不会自带 Meta 授权、爬虫、飞书凭据或数据。

| 问题 | 怎么处理 |
| --- | --- |
| 找不到 Skill | 检查安装窗口结果和目标 SKILL.md，重新打开 Codex 并新建对话。 |
| 程序启动失败 | 在程序目录打开 PowerShell 运行本文命令，让错误保留在窗口，再对照对应程序 README。 |
| 网页看不到插件 | 确认选中直接包含 manifest.json 的目录、网站受支持，并刷新网页。 |
| 外部服务不可用 | 配置自己的授权并检查资源权限；保留本地结果，不把失败说成同步/发送成功。 |
