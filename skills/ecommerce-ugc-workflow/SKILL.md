# 电商 UGC 流程 Skill

把用户的剧情想法和产品图片整理成可以直接用于 Google Omni 等视频模型的完整中文生产包。默认写清楚人物资产、场景、首帧、分段视频提示词和社媒文案，而不是只给剧情梗概。

## 1. 先读输入

优先读取用户提供的：

- 产品白底图、不同角度图和产品名称
- 人物图、人物三视图、上一段首帧和上一段成片
- 参考提示词、参考视频或分镜截图
- 时长、段数、平台、场景和剧情方向

有视频时，用 `ffprobe` 读取时长和画幅，用 `ffmpeg` 抽取均匀帧或关键帧。判断实际成片而不是只看原提示词。

不要凭空补充无法从产品图确认的结构。产品外观以用户上传图片为最高优先级。

## 2. 默认输出顺序

除非用户只要求其中一项，按以下顺序交付：

1. 故事定位与情绪曲线
2. 人物综合资产表提示词
3. 产品资产与强定义
4. 2–4个场景选择与场景提示词
5. 第一段首帧图提示词
6. 第一段完整视频提示词
7. 第二段首帧图提示词
8. 第二段完整视频提示词
9. 全局连续性与负面限制
10. TikTok 与 Instagram Reels 发布文案
11. 常见生成问题修复句

保存为 UTF-8 Markdown。使用明确文件名，例如：

`VARLA_M7S_剧情主题_Google_Omni双10秒完整版_YYYYMMDD.md`

## 3. 参考写法

写最终视频提示词前必须读取：

- `references/omni-story-framework.md`：两秒时间块、对白、人物与产品锁定
- `references/emotion-camera-direction.md`：强表情、小动作、多镜头和移动衔接
- `assets/output-template.md`：交付结构

主提示词采用经过验证的连续叙事写法：先锁定格式、人物和场景，再按约2秒一个自然段写清楚动作、表情、对白、因果和下一镜头衔接。不要把成片提示词写成抽象导演术语堆积。

## 4. 产品强绑定

产品名称使用用户指定的准确名称。VARLA M7S 必须直接写作 `VARLA M7S`。

每个首帧和视频提示词都要：

- 明确列出需要上传的产品图片
- 声明这些图片共同构成唯一产品真值
- 要求逐帧保持车型、颜色、车架、座椅、轮胎、前叉、悬挂、制动、灯具、车把、控制器、图案和标识
- 禁止重新设计、换色、变形、增减部件或替换车型
- 不确定的功能和启动方式不要编造

如果用户说“外观描述没用，直接用图片@强定义”，减少文字猜测，强化图片文件名引用和唯一真值声明。

## 5. 人物与真实皮肤

人物资产默认先做一张 9:16 综合人物设定表，而不是只有三视图。中央放最大比例的正面全身，左下放左前 45 度全身，右下放完整背面全身，三张全身图都必须从头顶到鞋底完整可见；左上、右上、左中、右中再放四个肩部以上表情近景，覆盖日常状态、怀疑或不开心、突然惊讶、最终强烈情绪。所有区域必须保持同一张脸、同一年龄、同一肤色、同一发型、同一身材和同一服装。使用整齐分区和细白色边框，但不生成标题、编号、Emoji、水印、器材结构图或乱码文字。只有用户明确要求传统三视图时，才改成正面、严格侧面和背面三栏结构。

人物提示词包含：

- 明确成年年龄或用户指定年龄
- 肤色、脸型、眼睛、头发、体型、身高和固定服装
- 鼻翼与面颊毛孔、额头细纹、眼下纹理、眼角浅纹、唇纹、细小绒毛、胡茬根部、轻微黑眼圈、局部泛红、晒斑、浅雀斑、微小痘印、肤色不均和自然油脂反光
- 普通人状态，不做模特笑容
- 无美颜滤镜、磨皮、祛斑、自动修脸、面部重塑、过度降噪、塑料皮肤、蜡像高光、假毛孔贴图、过度锐化、商业精修、CG或插画

后续所有提示词使用人物资产文件名强绑定身份。人物不得换脸、换发型、换衣服或无原因改变年龄和体型。

### 皮肤真实性硬锁定

皮肤可以好看，但不能像磨皮后的瓷器，也不能均匀成单一颜色。不同人物必须拥有不同位置、不同程度的毛孔、细纹、雀斑、痘印、泛红、晒斑、黑眼圈和肤色差，不得把一套相同瑕疵贴图复制到所有人脸上。

表情变化时，毛孔、皱纹、胡茬、雀斑与痘印应随真实肌肉和光线自然变化；它们不能在切镜后消失、漂移或换位置。水珠、汗液或泡沫应附着在真实皮肤起伏上，不能把脸覆盖成光滑塑料面具。正常瑕疵不要夸张成严重皮肤疾病。

这组要求不能只在人物资产里出现一次。必须在以下位置用短版或完整版重复锁定：

1. 人物综合资产表
2. 每个首帧提示词
3. 第一段视频任务开头
4. 第二段视频任务开头
5. 全局连续性与负面限制

如果用户只要求修改某几个故事或文件，仅修改用户点名的文件，不把新规则自动扩散到未点名作品或总合集。

## 6. 情绪表演是硬要求

每个说话镜头和反应镜头都必须同时写清：

1. 起始表情
2. 情绪触发物
3. 0.2–0.6秒理解停顿
4. 眉眼、眨眼、下巴、嘴角、脸颊和视线变化
5. 一至两个连贯小动作
6. 肩膀、躯干、手臂、脚步或身体重心变化
7. 声音变化
8. 镜头结束表情

不要只写“惊讶、悲伤、感动、崩溃、开心”。必须把情绪转成能拍到的真人动作。

表情和肢体动作要明显、夸张、适合手机小屏观看，但保留真实肌肉运动和身体惯性，不做卡通变脸。

### 喜剧反差

默认情绪阶梯：

`装作平静 -> 发现触发物 -> 僵住确认 -> 明显慌乱 -> 试图挽回 -> 最终反转时彻底崩溃`

最终反转是全片最大反应。搭档、家人和群众采用不同反应形态，不同步张嘴、转头、鼓掌或大笑。

### 家庭对话与礼物反转

家庭剧情同样保持强表演：

- 悲伤：低头、慢眨眼、嘴唇压紧、肩膀下沉、抓住衣角或包带、停顿后再说话
- 不开心：眉头内收、下巴绷紧、身体移开、抱臂后松开、视线回避
- 经济压力：看价格、看家人、吞咽、强笑后笑容消失、抓紧钱包或包带
- 突然收到礼物：僵住0.3–0.6秒、瞪大眼睛、张嘴、屏住呼吸、反复确认礼物和送礼人、捂嘴或双手放胸前、伸手又缩回、最后冲上前拥抱
- 感动释放：肩膀松开、眼眶湿润、哭笑交错、张开双臂、主动全身拥抱

礼物剧情必须有三个清楚状态：

`揭晓前失落或认命 -> 识别礼物时僵住不敢相信 -> 确认后大幅度惊喜释放`

短视频优先保留反应时间，通常每段只安排3–4句短对白；宁可减少一句对白，也不要删掉关键表情和动作。

## 7. 多镜头与镜头移动

默认镜头密度：

- 6秒：3个镜头
- 8秒：4个镜头
- 10秒：4–5个镜头

只有用户明确要求一镜到底时才减少切镜。

推荐结构：

`环境建立 -> 动作或道具细节 -> 人物反应近景 -> 反打 -> 产品/礼物揭晓广角 -> 共同反应`

每次切镜必须提供新信息或改变观众理解。使用动作、视线、声音和遮挡衔接：

- 手伸向手机，下一镜头接手机近景
- 人物看向画外，下一镜头揭示所看对象
- 通知音、车门声、笑声或对白跨切镜延续
- 人物或车辆经过前景时自然遮挡切镜

镜头移动必须写清起点、方向、跟随对象、速度和终点。逐组检查：

`上一镜头结束位置/方向/速度 -> 衔接依据 -> 下一镜头起始位置/方向/速度`

保持180度轴线、人物左右关系、车辆朝向、光线方向和移动方向。避免摄影机瞬移、无原因反向、突然升高、环绕、数字变焦抽动、漂浮稳定器感、无人机或商业大片运镜。

所有运镜都应像同一位朋友在附近拿着 iPhone：人物回头时自然横移，细节重要时靠近，礼物或车辆揭晓时后退拉开，表情需要阅读时短暂停稳。

## 8. 对白锁定

每段提示词先列对白总表，再把每句对白放进唯一所属镜头。

必须写清：

- 当前镜头唯一说话者
- 只有该人物出现口型
- 其他人物闭嘴，没有口型
- 系统通知音只能来自手机或设备
- 不得增加、删减、翻译、改写、重复或交换说话者
- 台词结束后保留可读反应，不要立即切走或恢复中性脸

如果时长无法容纳全部台词，主动删减对白并保留剧情动作，不要硬塞。

## 9. iPhone UGC 真实感

默认使用：

- 9:16竖屏
- 真实 Apple iPhone 后置主摄 1x 镜头拍摄质感
- 4K 30fps 普通视频
- 自然自动曝光和自然自动白平衡
- 轻微手持晃动、不完美构图、真实手机广角透视、普通手机锐化、真实运动模糊和环境底噪
- 使用手机普通视频常见的较深景深，让人物皮肤、关键道具和可辨认背景同时保留细节
- 允许摄影者随动作小步靠近或后退，也允许极轻微、缓慢、自然的缩放感；始终保持接近1x，不做突然数字变焦或变焦抽动
- 人物关注彼此、道具或车辆，不看镜头
- 真实室内商店、停车场、住宅车库、公园或便利店环境

禁止电影模式、人像模式、浅景深、过强背景虚化、稳定器商业跟拍、漂浮感、无人机、棚拍灯光、英雄定格、CG感和广告大片质感。

完整拍摄参数不能只在文件开头写一次。每个首帧、每个独立视频任务和全局负面限制都必须明确重复：`Apple iPhone 后置主摄 1x / 4K 30fps / 自然自动曝光 / 轻微手持 / 手机广角透视 / 可接受极轻微自然缩放 / 禁止电影模式 / 禁止人像模式 / 禁止浅景深 / 禁止商业广告运镜`。这样即使用户分段复制提示词，每一段仍然自足。

## 10. 群众反应

群众采用错峰反应链：一个人先注意，两个人稍后回头，另一个人捂嘴或与同伴交换眼神。不要让所有人排成半圆、同步鼓掌、同步张嘴或抢主角台词。

群众只强化主角情绪，不遮挡产品、主动作或对白人物。

所有工作人员、店员、主持人、摄影师、路人和宾客都必须是独立人物。其脸型、五官、肤色、发型、年龄感、体型和服装不得与任何主角重复，也不得在背景人群内部复制同一张脸或同一套衣服。提示词中明确写出“no duplicated people, no cloned faces, no repeated outfits, every background adult is visually distinct”，并在全局负面限制和群众修复句中重复一次。

## 11. 安全与合规

- 不提供危险特技教学
- 骑行保持低速、受控、无跳跃、漂移、摔车或追逐
- 未成年人不参与危险骑行；如果生成工具持续因年龄拒绝，改为明确19岁以上成年人物，不尝试绕过安全机制
- 不把种族、体型、年龄、汗水或外貌当作低能、肮脏或危险的原因；笑点来自误会、时机、选择和对白
- 不承诺平台审核一定通过

## 12. 发布文案

TikTok 和 Instagram 分开写：

- TikTok：第一句直接写反转或POV，第二句留下情绪梗，简短、口语化
- Instagram：增加一点人物关系和故事背景，仍保持简洁
- 产品名称保持准确
- 不写视频中没有出现的性能或危险动作

如果用户要求“最新流量最好的标签”，必须联网核实当前标签表现后再给，不要从旧提示词直接照抄。

## 13. 完成前检查

交付前逐项检查：

- 产品图片在每个相关提示词中被明确引用
- 人物资产、服装、场景和产品连续一致
- 人物资产、每个首帧、每段视频和全局限制均包含真实皮肤硬锁定，不依赖“同上”
- 鼻翼与面颊毛孔、眼下纹理、唇纹、绒毛、胡茬、雀斑、痘印、泛红、晒斑、肤色不均和自然油脂反光在近景中可见并跨镜头连续
- 每个首帧和视频任务都明确写出 Apple iPhone 后置主摄1x、4K 30fps、自然自动曝光、轻微手持、手机广角透视和自然轻微缩放
- 明确禁止电影模式、人像模式、浅景深、商业运镜、磨皮、美颜、祛斑和塑料皮肤
- 时间范围无缺口、重叠或超出总时长
- 镜头数量符合时长
- 每个镜头都有起始表情、触发、停顿、表情变化、小动作、身体反应和结束状态
- 每个切镜都有动作、视线、声音、遮挡或明确空间依据
- 镜头A的终点和镜头B的起点在位置、方向和速度上可衔接
- 每句对白只有一个说话者且时长可容纳
- 最终反转是最大的情绪峰值
- 结尾是人物关系或反应，而不是广告式产品Pose

可以运行：

```powershell
python scripts/validate_prompt.py "完整提示词.md"
```

检查器只负责结构性问题，不能替代人工判断产品准确性、表演自然度和镜头审美。
