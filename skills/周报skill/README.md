# Varla 社媒周报与月报 / Varla Social Weekly and Monthly Reports

**简体中文** | [English](README.en.md)

将用户提供的社媒截图和 CSV 按日期及平台核对，生成周环比、月报和飞书可粘贴表格。

## 功能特性

- 日期边界和可用数据检查
- 平台矩阵号与 KOL 指标合并
- 互动口径说明和粘贴表格

## 1. 先准备程序

### 社媒周报模板资料 (`varla-weekly-report`)

Codex 与你自己的截图/CSV。

先进入 `../../apps/varla-weekly-report`。按平台汇总、日期核对和周月报工作流指引。

1. 本目录是模板和 Skill 资料，没有需启动的后台。
2. 在完整包根目录运行 `安装Skill.cmd` 后重新打开 Codex。
3. 提供自己的当前与对比周期、截图和 CSV，用 周报skill 指定统计平台。
4. 逐项核对日期、互动口径和缺失数据，再使用输出表格。

[查看完整程序与浏览器插件安装说明](../../apps/varla-weekly-report/README.md)

没有业务截图、数据或自动登录后台功能。

## 当前限制与常见问题

varla-weekly-report 是模板/Skill 资料，没有独立网页程序；公开包不含业务截图、CSV 和历史报表。

| 问题 | 怎么处理 |
| --- | --- |
| 找不到 Skill | 检查安装窗口结果和目标 SKILL.md，重新打开 Codex 并新建对话。 |
| 程序启动失败 | 在程序目录打开 PowerShell 运行本文命令，让错误保留在窗口，再对照对应程序 README。 |
| 网页看不到插件 | 确认选中直接包含 manifest.json 的目录、网站受支持，并刷新网页。 |
| 外部服务不可用 | 配置自己的授权并检查资源权限；保留本地结果，不把失败说成同步/发送成功。 |
