# 情绪表演与镜头衔接

## 情绪不是形容词

把每个抽象情绪拆成可见表演：

- 眼睛：睁大、眯起、快速眨眼、慢眨眼、湿润、视线游移
- 眉毛：抬起、内收、单边抬起、突然放松
- 嘴和下巴：抿嘴、嘴角抽动、下巴掉下、嘴唇轻颤、笑容失守
- 呼吸：屏住、突然吸气、长呼气、喘气、说话前吞咽
- 手：抓紧、松开、捂嘴、摸后颈、擦汗、伸出又缩回、差点掉手机
- 身体：后退半步、前倾、肩膀塌下、身体僵住、弯腰笑、张开双臂、冲上前拥抱
- 声音：压低、停顿、语速加快、声音破裂、笑着说不完整

## 情绪阶梯

喜剧：

`10%自然 -> 30%注意 -> 60%不敢相信 -> 80%慌乱 -> 100%最终暴击`

家庭礼物：

`失落或认命 -> 看到线索 -> 僵住确认 -> 反复看礼物和家人 -> 捂嘴/后退 -> 冲上前拥抱或哭笑释放`

恋爱：

`装作不在意 -> 偷看 -> 被发现后回避 -> 对方回应 -> 忍笑 -> 明显心动或尴尬释放`

同一角色前后状态必须肉眼可见地不同。最终反转是全片最大反应。

## 小动作原则

每个镜头安排一至两个连续小动作，不能堆无关动作。例如：

```text
先抓紧包带，听见价格后手指慢慢松开；她低头吞咽，再抬眼强笑。
```

不要写成：

```text
她抓包、摸头、后退、转圈、鼓掌、擦眼泪。
```

动作要服务情绪并能在时长内完成。

## 多镜头结构

常用镜头链：

1. 环境中景：交代场地、人物和产品位置
2. 手部或道具近景：触发事件
3. 面部近景：读取第一反应
4. 反打：看到另一人的回应
5. 揭晓广角：产品、礼物和群体关系同框
6. 双人或群体中景：完成拥抱、笑崩或反差结尾

不要机械用满全部镜头。6秒通常选3个，8秒选4个，10秒选4–5个。

## 切镜衔接

### 动作衔接

镜头A：手伸向手机。

镜头B：手机近景从同一方向接住这只手，完成触碰。

### 视线衔接

镜头A：人物转眼看向画面右侧。

镜头B：从对应方向揭示车辆、礼物或另一个人物。

### 声音衔接

通知音、车门声、脚步、笑声或对白尾音跨越切镜，维持同一空间感。

### 遮挡衔接

人物、车辆或货架经过前景短暂遮住画面，在遮挡最满时硬切到下一机位。

## 镜头移动

每个移动镜头写四项：

1. 从哪里开始
2. 朝哪个方向移动
3. 跟随什么对象
4. 在哪里停下

示例：

```text
镜头从男主左前方约2米的中景开始，随着他转头向右轻轻横移；女主骑车经过前景时镜头继续向右跟随半步，最后停在男主与车辆同框的位置，稳定0.3秒读取他嘴硬又被吸引的表情。
```

相邻镜头检查：

```text
镜头A终点：右移、慢速、停在手机
衔接：手指继续向下
镜头B起点：手机从画面左下进入、同方向微移、接住手指动作
```

不要出现：

- 人物向右走，切镜后突然向左
- 前一镜头慢速手持，下一镜头无原因高速甩镜
- 摄影机突然从腰部高度跳到俯拍
- 对话双方左右位置交换
- 连续环绕人物或产品
- 漂浮稳定器、无人机、摇臂或广告运镜

## 群众

群众按不同延迟反应：

- 第一个人停下动作并看过去
- 第二个人稍后转头
- 第三个人捂嘴或碰一下同伴
- 同伴交换眼神

群众不说清晰台词，不排队，不同步鼓掌，不抢主角画面。
