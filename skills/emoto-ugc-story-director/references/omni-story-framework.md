# Google Omni 电摩剧情框架

## 核心写法

采用连续叙事式提示词，不要只给关键词。每个约2秒时间块写成一个完整自然段，按真实发生顺序描述：

`镜头和机位 -> 人物动作 -> 情绪触发 -> 面部变化 -> 小动作和身体反应 -> 对白 -> 镜头结束状态`

## 开头锁定段

每段视频开头先声明：

```text
生成[时长]秒、9:16竖屏超写实美国UGC短视频，真实Apple iPhone后置主摄1x拍摄质感，4K 30fps，自然自动曝光，轻微手持晃动，真实环境底噪。人物、服装、车辆、场景和光线与参考图保持一致。不要电影模式、夸张景深、商业灯光、CG感或广告大片感。人物不要看镜头。
```

## 人物锁定段

人物段落简洁但具体：

```text
[角色名]保持固定人物资产：[年龄、地区或族裔、身高、体型、肤色、脸型、眼睛、头发、服装、鞋、固定配件]。保留真实毛孔、肤色不均、眼下纹理、唇纹、汗珠或雀斑和自然面部不对称。不得换脸、换衣服、改变体型或变成广告模特。
```

## 产品锁定段

```text
@[产品图1] 与 @[产品图2] 共同构成 [产品准确名称] 唯一且最高优先级的产品真值。直接复制参考图中的产品，不依据文字重新设计。所有镜头逐帧保持相同车型、颜色、轮廓、车架、座椅、轮胎、前叉、悬挂、制动、灯具、车把、控制器、图案、标识和真实比例。不得变形、换色、增减部件或替换车型。
```

## 两秒时间块

推荐长度：

- 6秒：`0–2 / 2–4 / 4–6`
- 8秒：`0–2 / 2–4 / 4–6 / 6–8`
- 10秒：`0–2 / 2–4 / 4–6 / 6–8 / 8–10`

允许根据对白长度微调为 `0–2.2 / 2.2–4.1`，但必须完整覆盖时长且没有重叠。

每个时间块只放：

- 一个主要剧情动作
- 一个主要情绪变化
- 一至两个相互关联的小动作
- 一句短对白；必要时可放两句极短问答

## 对白锁定

先列总表：

```text
全片只允许以下清晰英文对白，必须逐字生成：
1. 角色A：“...”
2. 角色B：“...”
```

在每个镜头再次写：

```text
【说话者锁定】只有角色A说话，只有角色A出现准确口型。角色B和背景人物闭嘴且没有口型。
```

系统提示音必须标记来源，例如：

```text
手机发出系统音：“Order confirmed.” 这句话只能来自手机扬声器，任何人物不得说出。
```

## 第二段连续性

第二段开头明确继承：

```text
时间紧接第一段。人物身份、脸、体型、服装、汗水或泪痕状态、车辆、道具位置、场景布局、光线方向和情绪余韵保持完全一致。必须从第一段结束的准确视觉状态继续。
```

## 结尾

结束在人物反应上：笑弯腰、僵住、拥抱、交换眼神、含泪笑或崩溃大喊。产品保持清楚可见，但不要广告英雄定格，不要人物摆Pose或看镜头。
