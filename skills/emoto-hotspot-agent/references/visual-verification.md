# Visual Verification Rules

Use this before writing any e-moto hotspot report.

## Hard Gate

A candidate may not be recommended from title, hashtags, account name, or metrics alone.

Promote it only after the visual frames match the claimed content angle.

## Required Evidence

For every recommended item, write a short frame check:

- Opening frame:
- Middle frame:
- End frame:
- Confirmed content type:
- Mismatch risk:

If only a screenshot is available, describe exactly what is visible in that screenshot and mark the confidence as limited.

## Content Type Rules

### Wheelie / stunt

Frames must show the riding action itself. A title or hashtag with `wheelie`, `jump`, `stunt`, `surron`, or `talaria` is not enough.

### Clean build

Frames must show the bike as the main subject. Reject if the main subject is a pet, person, meme, unrelated product, or caption joke.

### POV ride

Frames must show handlebar, road/trail, rider perspective, or bike-mounted camera. Reject generic scenery if the bike is not clearly part of the content.

### Wash transformation

Frames must show before/after or the washing process. Reject if it is only a generic clean bike shot.

### Gift / garage reveal

Frames must show the reveal setup or reaction, with the bike as the payoff object.

## Rejection Labels

Use these plain labels in notes:

- `rejected: subject mismatch`
- `rejected: not enough frame evidence`
- `rejected: title-only signal`
- `rejected: weak metrics`
- `rejected: risk-heavy`

## Report Rule

If there are not enough verified items, write fewer recommendations. Do not invent a third item.
