# Varla Electric Mobility Skills and Tools

适用于电摩内容制作、海外社媒、KOL 协作与视频发布的公开脱敏版。包含 20 个 Skill 和 15 个配套程序或浏览器插件。

## 直接下载使用

打开 [独立下载与配套关系](独立下载清单.md)，按项目下载 ZIP。每个 Skill ZIP 已包含它需要的程序源码；程序也可单独下载。Skill 解压后双击 `安装Skill.cmd`；程序解压后双击 `打开程序文件夹.cmd`，按 README 安装依赖并配置自己的账号。下载整个仓库后也可双击 `安装到Codex.cmd`。

## 目录

- `skills/`：Skill 源文件。
- `apps/`：程序和浏览器插件源码。
- `packages/`：每个项目的独立 ZIP。

本仓库只使用先前经过隐私清理和文件核对的发布副本。未收录真实账号凭据、KOL/客户记录、合同、订单、邮件、业务数据库及原始媒体素材。部分程序需要用户在自己的电脑上配置第三方服务，详见 [隐私清理说明](隐私清理说明.md)。
