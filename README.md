# Varla Electric Mobility Skills and Tools

适用于电摩内容制作、海外社媒、KOL 协作与视频发布的公开脱敏版。包含 20 个 Skill 和 15 个配套程序或浏览器插件。

## 直接下载使用

1. 打开[完整项目下载清单](独立下载清单.md)，先按程序找到对应 Skill，再下载该行的**完整项目 ZIP**。一个包里已有程序源码和 Skill，无需分别下载两遍。
2. 解压后先双击 `打开程序文件夹.cmd`，阅读程序说明并配置自己的依赖和账号；然后双击 `安装Skill.cmd` 安装 Skill。没有独立程序的 Skill 可直接按自己的说明使用。
3. [独立 GitHub 仓库清单](独立仓库清单.md)只列已经上传的完整项目仓库。还没有独立仓库的项目，完整 ZIP 也已放在本合集的 `packages/` 目录，能直接下载。

下载整个仓库后也可双击 `安装到Codex.cmd` 一次安装全部 Skill。13 个配套程序另有单独 ZIP，仅需单独使用程序时才下载；另有 2 个工具暂时没有对应 Skill，列在下载清单末尾。

## 目录

- `skills/`：Skill 源文件。
- `apps/`：程序和浏览器插件源码。
- `packages/`：每个项目的独立 ZIP。

本仓库只使用先前经过隐私清理和文件核对的发布副本。未收录真实账号凭据、KOL/客户记录、合同、订单、邮件、业务数据库及原始媒体素材。部分程序需要用户在自己的电脑上配置第三方服务，详见 [隐私清理说明](隐私清理说明.md)。
