# Blockers

- Docker CLI is not installed on this workstation, so Docker Compose cannot yet be executed locally.
- Meta phase requires a configured Meta developer app, test Page, linked Instagram professional account, permissions and OAuth credentials.
- TikTok phase requires a configured developer app, scopes, test account, audit status and OAuth credentials.
- `S3_PUBLIC_BASE_URL` must be an externally reachable HTTPS URL before any real platform submission; localhost is rejected by design.
