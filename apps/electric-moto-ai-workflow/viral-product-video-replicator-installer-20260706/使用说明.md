# viral-product-video-replicator 安装包

这个包用于把 `viral-product-video-replicator` skill 安装到另一台 Windows 电脑的 Codex。

## 安装

1. 解压整个压缩包。
2. 双击 `安装到Codex.cmd`。
3. 安装完成后，重启 Codex。

安装位置：

```text
%USERPROFILE%\.codex\skills\viral-product-video-replicator
```

如果电脑里已经有旧版同名 skill，安装脚本会先把旧版改名备份，不会直接删除。

## 验证

右键 `验证安装.ps1`，选择用 PowerShell 运行，或者在 PowerShell 里执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\验证安装.ps1"
```

看到 `OK: skill is installed.` 就说明安装成功。

## 怎么用

重启 Codex 后，可以这样说：

```text
用 viral-product-video-replicator 拆解这个爆款视频，替换成我的产品，生成分镜、即梦提示词和 TikTok/INS 文案。
```

也可以说：

```text
帮我生成一个电摩产品视频的18宫格故事板提示词，再拆成3段即梦提示词。
```

## 包内文件

- `viral-product-video-replicator/`：skill 本体

- `install_windows.ps1`：安装脚本
- `验证安装.ps1`：检查是否安装成功
- `使用说明.md`：这份说明
