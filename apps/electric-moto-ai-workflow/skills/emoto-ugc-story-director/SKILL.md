# 电摩 UGC 剧情导演

把用户的剧情想法和产品图片整理成可以直接用于 Google Omni 等视频模型的完整中文生产包。默认写清楚人物资产、场景、首帧、分段视频提示词和社媒文案，而不是只给剧情梗概。

## 1. 先读输入

优先读取用户提供的：

- 产品白底图、不同角度图和产品名称
- 人物图、人物三视图、上一段首帧和上一段成片
- 参考提示词、参考视频或分镜截图
- 时长、段数、平台、场景和剧情方向

有视频时，用 `ffprobe` 读取时长和画幅，用 `ffmpeg` 抽取均匀帧或关键帧。判断实际成片而不是只看原提示词。

不要凭空补充无法从产品图确认的结构。产品外观以用户上传图片为最高优先级。

## 2. 默认输出顺序

除非用户只要求其中一项，按以下顺序交付：

1. 故事一句话和情绪弧线
2. 人物资产三视图提示词
3. 2–4个场景选择及对应首帧提示词
4. 产品与人物强绑定规则
5. 第一段完整视频提示词
6. 第二段完整视频提示词
7. TikTok 发布文案
8. Instagram Reels 发布文案
9. 生成失败时的定向修正规则

保存为 UTF-8 Markdown。使用明确文件名，例如：

`VARLA_M7S_剧情主题_Google_Omni双10秒完整版_YYYYMMDD.md`

## 3. 参考写法

写最终视频提示词前必须读取：

- `references/omni-story-framework.md`：两秒时间块、对白、人物与产品锁定
- `references/emotion-camera-direction.md`：强表情、小动作、多镜头和移动衔接
- `assets/output-template.md`：交付结构

主提示词采用经过验证的连续叙事写法：先锁定格式、人物和场景，再按约2秒一个自然段写清楚动作、表情、对白、因果和下一镜头衔接。不要把成片提示词写成抽象导演术语堆积。

## 4. 产品强绑定

产品名称使用用户指定的准确名称。VARLA M7S 必须直接写作 `VARLA M7S`。

每个首帧和视频提示词都要：

- 明确列出需要上传的产品图片
- 声明这些图片共同构成唯一产品真值
- 要求逐帧保持车型、颜色、车架、座椅、轮胎、前叉、悬挂、制动、灯具、车把、控制器、图案和标识
- 禁止重新设计、换色、变形、增减部件或替换车型
- 不确定的功能和启动方式不要编造

如果用户说“外观描述没用，直接用图片@强定义”，减少文字猜测，强化图片文件名引用和唯一真值声明。

## 5. 人物与真实皮肤

人物资产先做三视图：同一身份的正面、严格侧面和背面全身，等比例、同服装、浅灰背景、自然站立、脚部完整，不拿场景道具。

人物提示词包含：

- 明确成年年龄或用户指定年龄
- 肤色、脸型、眼睛、头发、体型、身高和固定服装
- 毛孔、汗珠、雀斑、肤色不均、眼下纹理、唇纹、细小绒毛和轻微面部不对称
- 普通人状态，不做模特笑容
- 无磨皮、塑料皮肤、美颜、商业精修、CG或插画

后续所有提示词使用人物资产文件名强绑定身份。人物不得换脸、换发型、换衣服或无原因改变年龄和体型。

## 6. 情绪表演是硬要求

每个说话镜头和反应镜头都必须同时写清：

1. 起始表情
2. 情绪触发物
3. 0.2–0.6秒理解停顿
4. 眉眼、眨眼、下巴、嘴角、脸颊和视线变化
5. 一至两个连贯小动作
6. 肩膀、躯干、手臂、脚步或身体重心变化
7. 声音变化
8. 镜头结束表情

不要只写“惊讶、悲伤、感动、崩溃、开心”。必须把情绪转成能拍到的真人动作。

表情和肢体动作要明显、夸张、适合手机小屏观看，但保留真实肌肉运动和身体惯性，不做卡通变脸。

### 喜剧反差

默认情绪阶梯：

`装作平静 -> 发现触发物 -> 僵住确认 -> 明显慌乱 -> 试图挽回 -> 最终反转时彻底崩溃`

最终反转是全片最大反应。搭档、家人和群众采用不同反应形态，不同步张嘴、转头、鼓掌或大笑。

### 家庭对话与礼物反转

家庭剧情同样保持强表演：

- 悲伤：低头、慢眨眼、嘴唇压紧、肩膀下沉、抓住衣角或包带、停顿后再说话
- 不开心：眉头内收、下巴绷紧、身体移开、抱臂后松开、视线回避
- 经济压力：看价格、看家人、吞咽、强笑后笑容消失、抓紧钱包或包带
- 突然收到礼物：僵住0.3–0.6秒、瞪大眼睛、张嘴、屏住呼吸、反复确认礼物和送礼人、捂嘴或双手放胸前、伸手又缩回、最后冲上前拥抱
- 感动释放：肩膀松开、眼眶湿润、哭笑交错、张开双臂、主动全身拥抱

礼物剧情必须有三个清楚状态：

`揭晓前失落或认命 -> 识别礼物时僵住不敢相信 -> 确认后大幅度惊喜释放`

短视频优先保留反应时间，通常每段只安排3–4句短对白；宁可减少一句对白，也不要删掉关键表情和动作。

## 7. 多镜头与镜头移动

默认镜头密度：

- 6秒：3个镜头
- 8秒：4个镜头
- 10秒：4–5个镜头

只有用户明确要求一镜到底时才减少切镜。

推荐结构：

`环境建立 -> 动作或道具细节 -> 人物反应近景 -> 反打 -> 产品/礼物揭晓广角 -> 共同反应`

每次切镜必须提供新信息或改变观众理解。使用动作、视线、声音和遮挡衔接：

- 手伸向手机，下一镜头接手机近景
- 人物看向画外，下一镜头揭示所看对象
- 通知音、车门声、笑声或对白跨切镜延续
- 人物或车辆经过前景时自然遮挡切镜

镜头移动必须写清起点、方向、跟随对象、速度和终点。逐组检查：

`上一镜头结束位置/方向/速度 -> 衔接依据 -> 下一镜头起始位置/方向/速度`

保持180度轴线、人物左右关系、车辆朝向、光线方向和移动方向。避免摄影机瞬移、无原因反向、突然升高、环绕、数字变焦抽动、漂浮稳定器感、无人机或商业大片运镜。

所有运镜都应像同一位朋友在附近拿着 iPhone：人物回头时自然横移，细节重要时靠近，礼物或车辆揭晓时后退拉开，表情需要阅读时短暂停稳。

## 8. 对白锁定

每段提示词先列对白总表，再把每句对白放进唯一所属镜头。

必须写清：

- 当前镜头唯一说话者
- 只有该人物出现口型
- 其他人物闭嘴，没有口型
- 系统通知音只能来自手机或设备
- 不得增加、删减、翻译、改写、重复或交换说话者
- 台词结束后保留可读反应，不要立即切走或恢复中性脸

如果时长无法容纳全部台词，主动删减对白并保留剧情动作，不要硬塞。

## 9. iPhone UGC 真实感

默认使用：

- 9:16竖屏
- Apple iPhone 后置主摄1x
- 4K 30fps普通视频
- 轻微手持晃动、不完美构图、自然自动曝光、普通手机锐化、真实运动模糊和环境底噪
- 人物关注彼此、道具或车辆，不看镜头
- 真实室内商店、停车场、住宅车库、公园或便利店环境

禁止电影模式、夸张浅景深、稳定器商业跟拍、棚拍灯光、英雄定格、CG感和广告大片质感。

## 10. 群众反应

群众采用错峰反应链：一个人先注意，两个人稍后回头，另一个人捂嘴或与同伴交换眼神。不要让所有人排成半圆、同步鼓掌、同步张嘴或抢主角台词。

群众只强化主角情绪，不遮挡产品、主动作或对白人物。

## 11. 安全与合规

- 不提供危险特技教学
- 骑行保持低速、受控、无跳跃、漂移、摔车或追逐
- 未成年人不参与危险骑行；如果生成工具持续因年龄拒绝，改为明确19岁以上成年人物，不尝试绕过安全机制
- 不把种族、体型、年龄、汗水或外貌当作低能、肮脏或危险的原因；笑点来自误会、时机、选择和对白
- 不承诺平台审核一定通过

## 12. 发布文案

TikTok 和 Instagram 分开写：

- TikTok：第一句直接写反转或POV，第二句留下情绪梗，简短、口语化
- Instagram：增加一点人物关系和故事背景，仍保持简洁
- 产品名称保持准确
- 不写视频中没有出现的性能或危险动作

如果用户要求“最新流量最好的标签”，必须联网核实当前标签表现后再给，不要从旧提示词直接照抄。

## 13. 完成前检查

交付前逐项检查：

- 产品图片在每个相关提示词中被明确引用
- 人物资产、服装、场景和产品连续一致
- 时间范围无缺口、重叠或超出总时长
- 镜头数量符合时长
- 每个镜头都有起始表情、触发、停顿、表情变化、小动作、身体反应和结束状态
- 每个切镜都有动作、视线、声音、遮挡或明确空间依据
- 镜头A的终点和镜头B的起点在位置、方向和速度上可衔接
- 每句对白只有一个说话者且时长可容纳
- 最终反转是最大的情绪峰值
- 结尾是人物关系或反应，而不是广告式产品Pose

可以运行：

```powershell
python scripts/validate_prompt.py "完整提示词.md"
```

检查器只负责结构性问题，不能替代人工判断产品准确性、表演自然度和镜头审美。
