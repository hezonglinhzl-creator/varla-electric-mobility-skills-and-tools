# 飞书原生表格分镜模板

这是本地视频拆镜头工具的默认飞书输出模板。输出必须能直接复制粘贴到飞书文档或飞书表格中。

## 固定表头

时间 | 画面参考（竖屏9:16） | 画面描述 | 角色动作 / 镜头运动 | 对话 / 声音 | 备注

## Markdown 表格格式

不要输出 HTML 表格，不要输出图片表格，不要用截图形式。单元格内尽量使用短句、顿号、分号分隔，避免复杂换行。必须换行时使用 `<br>`。

| 时间 | 画面参考（竖屏9:16） | 画面描述 | 角色动作 / 镜头运动 | 对话 / 声音 | 备注 |
|---|---|---|---|---|---|
| 0-3s | 画面参考说明 | 画面描述 | 动作与镜头 | 对话与声音 | 备注 |
| 3-6s | 画面参考说明 | 画面描述 | 动作与镜头 | 对话与声音 | 备注 |

## TSV 表格格式

用于粘贴到飞书表格、多维表格或 Excel。字段顺序固定，不要合并单元格。

```tsv
时间	画面参考（竖屏9:16）	画面描述	角色动作 / 镜头运动	对话 / 声音	备注
0-3s	画面参考说明	画面描述	动作与镜头	对话与声音	备注
```
